# Learing Rust From Scratch Through Many Docs #

I like to learn things through read documentation and code examples from GitHub.

**There will be no video tutorial in this repo.**

## Resources ##

- [Get started with Rust](https://www.rust-lang.org/learn)
- [Tour of Rust](https://tourofrust.com/index.html)
- [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/)

## How To Run ##

```shell
git clone https://github.com/KS-Arafat/rust-basics
```

or

[Download](https://github.com/KS-Arafat/rust-basics/archive/refs/heads/main.zip) and [Unzip](https://7-zip.org/) the archive.

Then,

```shell
cd rust-basics
cargo r
```

### And Done ###
